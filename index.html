WCAG 2.1 AA Audit Criteria

  • Contrast Ratio: Minimum 4.5:1 ratio for normal body text and 3:1 for large text.
  • Focus Visible: High-contrast focus outlines for every interactive element.
  • Form Labels: Explicit for and id association on all controls.
  • Live Announcements: aria-live="polite" for dynamic validation feedback.
